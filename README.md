# SDP bonus tasks

20 независимых решений пяти паттернов на Java 21, Gradle 8.13 и JUnit 5.

Начните с [BONUS_TASKS_README.md](BONUS_TASKS_README.md): команды, таблица модулей и допущения.
Для защиты используйте [DEFENSE_NOTES.md](DEFENSE_NOTES.md) и
[RUBRIC_CHECKLIST.md](RUBRIC_CHECKLIST.md).

Windows: `powershell -ExecutionPolicy Bypass -File .\run-gradle.ps1 build`.
При настроенном JDK 21: `./gradlew build`.
